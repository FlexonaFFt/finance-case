# Архитектура проекта

## Компоненты
- **API (FastAPI)** — CRUD клиентов, счета, транзакции, переводы. Работает поверх Postgres, пишет логи переводов в Mongo.
- **Postgres** — источник истины: клиенты, счета, транзакции, переводы.
- **MongoDB** — коллекция `transfer_events` для логов переводов (аудит/диагностика).
- **Telegram-бот** — обертка над API: регистрация/логин, просмотр счетов, пополнение, перевод.

## Схема данных (Postgres)
- `clients(id, name, email, password_hash, created_at)`
- `accounts(id, client_id, currency, balance_minor, created_at)` — id вида `0000-abcd-000-000`, баланс в минорных единицах.
- `transactions(id, account_id, amount_minor, currency, description, occurred_at, created_at)` — все движения (депозиты, списания, переводы).
- `transfers(id, from_account_id, to_account_id, amount_minor, currency, description, created_at)` — факт перевода между счетами.

## Потоки
1. Регистрация/логин → выдача JWT.
2. Создание счета: автоматически RUB со стартовым балансом 0 (или через эндпоинт для доп. счетов).
3. Депозит/списание: `POST /transactions` — меняет баланс счета, пишет транзакцию.
4. Перевод: `POST /transfers` — проверка владельца источника и валюты, списание на источнике, зачисление на получателе, запись в `transfers` и две записи в `transactions`, лог в Mongo.
5. Бот использует API: пошаговая авторизация, выбор счетов (до 5), пополнение, перевод.

## Запуск
- Всё в Docker: `docker compose up --build -d`.
- Postgres: порт 5432, креды из `.env`.
- Mongo: порт 27017, без авторизации.
- API: `http://localhost:8000`, бот — в составе docker-compose (нужен `BOT_TOKEN`).

## Почему Mongo
- Храним логи переводов вне основной БД, чтобы не раздувать ledger и иметь отдельный канал для аудита/диагностики. При необходимости можно расширить схему (corr-id, raw payload, попытки).

## Ограничения и следующий шаг
- Нет валидации валют при создании доп. счетов (кроме ручной проверки в запросе) — можно добавить справочник валют.
- Нет лимитов/фрод-правил — кандидаты на отдельный сервис.
- Токены/сессии — простая JWT без refresh/rotations.
